# Primary-python-project-of-mine# 
Python Conditional Statements and Input Practice

A beginner Python project containing ten interactive exercises. Each exercise asks for input, applies basic conditional logic, and displays a result.

The notebook is intended for learning and practice. It does not connect to real banking, billing, university, hiring, or authentication systems.

## Project contents

The exercises are in one Jupyter notebook:

| # | Exercise | What it practices |
|---|---|---|
| 1 | Temperature check | Comparing a temperature with conditions |
| 2 | ATM withdrawal simulation | Checking a withdrawal against a balance and calculating the remaining balance |
| 3 | Student grade calculator | Mapping marks to a grade and CGPA |
| 4 | Bus ticket discount | Applying example ticket prices based on age |
| 5 | Restaurant bill discount | Applying a discount above a bill threshold |
| 6 | Login check | Comparing entered details with values in the code |
| 7 | Traffic light system | Selecting an instruction based on a colour |
| 8 | Leap year checker | Checking a year using divisibility rules |
| 9 | Job eligibility checker | Checking an age condition |
| 10 | Electricity bill calculator | Selecting a rate based on the number of units |

## Concepts covered

- Variables and data types
- Reading input with `input()`
- Converting input with `int()` and `float()`
- Conditional statements: `if`, `elif`, and `else`
- Comparison and logical operators
- Basic arithmetic
- Printing results with `print()`

## Requirements

- Python 3
- Jupyter Notebook, or a compatible notebook environment such as Google Colab

The exercises use Python’s built-in features and do not require additional packages.

## Run the notebook locally

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install Jupyter Notebook if needed:

   ```bash
   python -m pip install notebook
   ```

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `Untitled5.ipynb`.
6. Run the cells and enter values when prompted.

You can also open the notebook in Google Colab by uploading `Untitled5.ipynb` to Colab.
